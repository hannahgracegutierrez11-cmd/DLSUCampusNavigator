DLSU Facility Navigator is a navigation program that shows the 2D layout of the possible routes and directions depending on the current location of the user to the desired destination within the ground inside De La Salle University Manila Campus. The program shall have a Graphical User Interface (GUI), where users can select their location and destination  through a drop down chip and is limited to gates 1 and 2, Henry Sy Building, Velasco Building, and St. Miguel Building. With the inputs, the program will be displaying the directions between gate to buildings or building to building along with a map to visualize the route. This will serve as a guide for users to locate facilities within the premises of the Manila Campus.
